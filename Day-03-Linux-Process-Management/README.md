Day 3 of my #45DaysOfDevOps challenge — Linux Process Management.

Today I studied the theory behind Linux process management — how the kernel schedules, monitors, and controls processes. Tomorrow, I'll be implementing this hands-on in a live terminal and documenting the output.

What I learned today:
• How Linux assigns PIDs and manages process lifecycles
• Difference between SIGTERM (kill -15) and SIGKILL (kill -9)
• Process priority with nice and renice
• Parent-child process relationships (pstree)
• Load average and system monitoring (uptime, top)

Why it matters:
In production, when a server slows down or a container eats memory, process management is the first skill you use. It's not optional — it's foundational.
